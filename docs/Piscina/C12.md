# C12

## Objetivo

Listas enlazadas simples (`t_list`): crear, recorrer, modificar, ordenar y fusionar.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_create_elem` | Crea un nodo |
| ex01 | `ft_list_push_front` | Inserta al inicio |
| ex02 | `ft_list_size` | Tamaño de la lista |
| ex03 | `ft_list_last` | Último nodo |
| ex04 | `ft_list_push_back` | Inserta al final |
| ex05 | `ft_list_push_strs` | Lista a partir de un array de strings |
| ex06 | `ft_list_clear` | Libera la lista |
| ex07 | `ft_list_at` | Nodo en la posición `nbr` |
| ex08 | `ft_list_reverse` | Invierte la lista (punteros) |
| ex09 | `ft_list_foreach` | Aplica `f` a cada dato |
| ex10 | `ft_list_foreach_if` | Aplica `f` si `data_ref` coincide |
| ex11 | `ft_list_find` | Busca el primer nodo coincidente |
| ex12 | `ft_list_remove_if` | Elimina nodos que cumplen la condición |
| ex13 | `ft_list_merge` | Concatena dos listas |
| ex14 | `ft_list_sort` | Ordena la lista |
| ex15 | `ft_list_reverse_fun` | Invierte intercambiando datos |
| ex16 | `ft_sorted_list_insert` | Inserta manteniendo orden |
| ex17 | `ft_sorted_list_merge` | Fusiona dos listas ordenadas |

## Cómo probar

```bash
make -C src/Piscina/C12
make -C src/Piscina/C12/ex00 && ./src/Piscina/C12/ex00/test_ex00.out
```

## Notas

Cada ejercicio incluye su `ft_list.h` local.
