# C01

## Objetivo

Punteros y arrays: dereferenciar, intercambiar, dividir y manipular tablas de enteros.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_ft` | Asigna `42` vía puntero |
| ex01 | `ft_ultimate_ft` | Igual con 9 niveles de indirección |
| ex02 | `ft_swap` | Intercambia dos `int` |
| ex03 | `ft_div_mod` | Cociente y resto en punteros |
| ex04 | `ft_ultimate_div_mod` | División/módulo in-place |
| ex05 | `ft_putstr` | Imprime una cadena |
| ex06 | `ft_strlen` | Longitud de cadena |
| ex07 | `ft_rev_int_tab` | Invierte un array de `int` |
| ex08 | `ft_sort_int_tab` | Ordena un array de `int` |

## Cómo probar

```bash
make -C src/Piscina/C01
make -C src/Piscina/C01/ex00 && ./src/Piscina/C01/ex00/test_ex00.out
```
