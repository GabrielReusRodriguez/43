# C07

## Objetivo

Asignación dinámica con `malloc`: duplicar strings, rangos, join, conversión de bases y `split`.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_strdup` | Duplica una cadena |
| ex01 | `ft_range` | Array de enteros `[min, max)` |
| ex02 | `ft_ultimate_range` | Igual vía puntero doble; devuelve tamaño |
| ex03 | `ft_strjoin` | Une un array de strings con separador |
| ex04 | `ft_convert_base` / `ft_convert_base2` | Convierte un número entre dos bases |
| ex05 | `ft_split` | Parte una cadena según charset |

## Cómo probar

```bash
make -C src/Piscina/C07
make -C src/Piscina/C07/ex00 && ./src/Piscina/C07/ex00/test_ex00.out
```

## Notas

`ex04` reparte la lógica en dos `.c` (`ft_convert_base.c` y `ft_convert_base2.c`).
