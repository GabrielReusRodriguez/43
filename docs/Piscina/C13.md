# C13

## Objetivo

Árboles binarios (`t_btree`): creación, recorridos, inserción, búsqueda y niveles.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `btree_create_node` | Crea un nodo |
| ex01 | `btree_apply_prefix` | Recorrido prefijo |
| ex02 | `btree_apply_infix` | Recorrido infijo |
| ex03 | `btree_apply_suffix` | Recorrido sufijo / postorden |
| ex04 | `btree_insert_data` | Inserta según `cmpf` |
| ex05 | `btree_search_item` | Busca un ítem |
| ex06 | `btree_level_count` | Profundidad / nº de niveles |
| ex07 | `btree_apply_by_level` | Aplica una función nivel a nivel |

## Cómo probar

```bash
make -C src/Piscina/C13
make -C src/Piscina/C13/ex00 && ./src/Piscina/C13/ex00/test_ex00.out
```

## Notas

Cada ejercicio incluye su `ft_btree.h` local.
