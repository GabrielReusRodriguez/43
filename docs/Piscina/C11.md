# C11

## Objetivo

Punteros a función: map/foreach, predicados, ordenación y la calculadora `do-op`.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_foreach` | Aplica una función a cada `int` del array |
| ex01 | `ft_map` | Devuelve un array transformado |
| ex02 | `ft_any` | ¿Algún string cumple el predicado? |
| ex03 | `ft_count_if` | Cuenta strings que cumplen el predicado |
| ex04 | `ft_is_sort` | ¿Array ordenado según `cmp`? |
| ex05 | `ft_do_op` (+ `ft_atoi`, `ft_arithmetic`, `ft_put`) | Calculadora `a op b` por argv |
| ex06 | `ft_sort_string_tab` | Ordena un array de strings (ASCII) |
| ex07 | `ft_advanced_sort_string_tab` | Ordena con función de comparación |

## Cómo probar

```bash
make -C src/Piscina/C11
make -C src/Piscina/C11/ex05
./src/Piscina/C11/ex05/do-op.out 42 + 21
make -C src/Piscina/C11/ex06 && ./src/Piscina/C11/ex06/test_ex06.out
```

## Notas

Algunos `src/test.c` de ex00–ex04 son stubs (`return 0`); el build pasa igual.
