# C04

## Objetivo

Conversión e impresión de números, incluido trabajo con bases arbitrarias.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_strlen` | Longitud de cadena |
| ex01 | `ft_putstr` | Imprime una cadena |
| ex02 | `ft_putnbr` | Imprime un `int` |
| ex03 | `ft_atoi` | Convierte string a `int` |
| ex04 | `ft_putnbr_base` | Imprime un número en una base dada |
| ex05 | `ft_atoi_base` | Parsea un número en una base dada |

## Cómo probar

```bash
make -C src/Piscina/C04
make -C src/Piscina/C04/ex03 && ./src/Piscina/C04/ex03/test_ex03.out
```
