# C06

## Objetivo

Programas con `argc`/`argv`: imprimir y ordenar argumentos de línea de comandos.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_print_program_name` | Imprime el nombre del programa |
| ex01 | `ft_print_params` | Imprime cada argumento (uno por línea) |
| ex02 | `ft_rev_params` | Igual, en orden inverso |
| ex03 | `ft_sort_params` | Imprime los argumentos ordenados |

## Cómo probar

```bash
make -C src/Piscina/C06
make -C src/Piscina/C06/ex01
./src/Piscina/C06/ex01/test_ex01.out a c b
```
