# C10

## Objetivo

Programas de ficheros al estilo Unix: mostrar un fichero, `cat` y `tail`.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_display_file` | Muestra el contenido de un fichero |
| ex01 | `ft_cat` (+ helpers) | Replica `cat` (ficheros / stdin) |
| ex02 | `ft_tail` (+ helpers) | Replica `tail` (`-c`, varios ficheros) |

## Cómo probar

```bash
make -C src/Piscina/C10/ex00
./src/Piscina/C10/ex00/test_ex00.out src/Piscina/C10/ex00/examples/test.txt

make -C src/Piscina/C10/ex01
./src/Piscina/C10/ex01/ft_cat.out src/Piscina/C10/ex01/examples/test.txt

make -C src/Piscina/C10/ex02
./src/Piscina/C10/ex02/ft_tail.out -c 10 src/Piscina/C10/ex02/examples/test.txt
```

## Notas

`ex01`/`ex02` están repartidos en varios `.c`/`.h` (`ft_buffer`, `ft_string`, `ft_file`/`ft_args`, etc.).
