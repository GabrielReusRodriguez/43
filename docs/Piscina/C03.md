# C03

## Objetivo

Reimplementar funciones clásicas de comparación y concatenación de strings.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_strcmp` | Compara dos cadenas |
| ex01 | `ft_strncmp` | Compara como máximo `n` chars |
| ex02 | `ft_strcat` | Concatena al final de `dest` |
| ex03 | `ft_strncat` | Concatena como máximo `nb` chars |
| ex04 | `ft_strstr` | Busca una subcadena |
| ex05 | `ft_strlcat` | Concatenación acotada (estilo BSD) |

## Cómo probar

```bash
make -C src/Piscina/C03
make -C src/Piscina/C03/ex00 && ./src/Piscina/C03/ex00/test_ex00.out
```
