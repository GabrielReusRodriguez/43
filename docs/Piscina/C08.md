# C08

## Objetivo

Cabeceras, macros y estructuras: biblioteca mínima, booleanos, abs, puntos y `t_stock_str`.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft.h` | Header con prototipos básicos |
| ex01 | `ft_boolean.h` | Macros booleanas (`TRUE`/`FALSE`, etc.) |
| ex02 | `ft_abs.h` | Macro `ABS` |
| ex03 | `ft_point.h` | Struct `t_point` |
| ex04 | `ft_strs_to_tab` | Rellena un array de `t_stock_str` |
| ex05 | `ft_show_tab` | Imprime un array de `t_stock_str` |

## Cómo probar

```bash
make -C src/Piscina/C08
make -C src/Piscina/C08/ex01 && ./src/Piscina/C08/ex01/test_ex01.out
make -C src/Piscina/C08/ex04 && ./src/Piscina/C08/ex04/test_ex04.out
```

## Notas

`ex00`–`ex03` son sobre todo headers; `ex04`/`ex05` incluyen `ft_stock_str.h`.
