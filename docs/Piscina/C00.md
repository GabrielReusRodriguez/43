# C00

## Objetivo

Primeros pasos en C: `write`, bucles y generación de combinaciones numéricas.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_putchar` | Escribe un carácter |
| ex01 | `ft_print_alphabet` | Imprime `a`–`z` |
| ex02 | `ft_print_reverse_alphabet` | Imprime `z`–`a` |
| ex03 | `ft_print_numbers` | Imprime `0`–`9` |
| ex04 | `ft_is_negative` | Imprime `N` o `P` según el signo |
| ex05 | `ft_print_comb` | Combinaciones de 3 dígitos distintos |
| ex06 | `ft_print_comb2` | Pares de números `00 01` … `98 99` |
| ex07 | `ft_putnbr` | Imprime un `int` (incluye `INT_MIN`) |
| ex08 | `ft_print_combn` | Combinaciones crecientes de `n` dígitos |

## Cómo probar

```bash
make -C src/Piscina/C00
make -C src/Piscina/C00/ex00
./src/Piscina/C00/ex00/test_ex00.out
```
