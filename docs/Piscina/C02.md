# C02

## Objetivo

Manipulación y validación de strings: copia, case, capitalización y volcado de memoria.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_strcpy` | Copia una cadena |
| ex01 | `ft_strncpy` | Copia como máximo `n` caracteres |
| ex02 | `ft_str_is_alpha` | ¿Solo letras? |
| ex03 | `ft_str_is_numeric` | ¿Solo dígitos? |
| ex04 | `ft_str_is_lowercase` | ¿Solo minúsculas? |
| ex05 | `ft_str_is_uppercase` | ¿Solo mayúsculas? |
| ex06 | `ft_str_is_printable` | ¿Solo imprimibles? |
| ex07 | `ft_strupcase` | Convierte a mayúsculas |
| ex08 | `ft_strlowcase` | Convierte a minúsculas |
| ex09 | `ft_strcapitalize` | Capitaliza palabras |
| ex10 | `ft_strlcpy` | Copia acotada (estilo BSD) |
| ex11 | `ft_putstr_non_printable` | Escapa no imprimibles en hex |
| ex12 | `ft_print_memory` | Hexdump estilo memoria |

## Cómo probar

```bash
make -C src/Piscina/C02
make -C src/Piscina/C02/ex00 && ./src/Piscina/C02/ex00/test_ex00.out
```
