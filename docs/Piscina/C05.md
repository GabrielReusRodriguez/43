# C05

## Objetivo

Recursividad e iteración: factorial, potencia, Fibonacci, primos y el puzzle de las 10 reinas.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `ft_iterative_factorial` | Factorial iterativo |
| ex01 | `ft_recursive_factorial` | Factorial recursivo |
| ex02 | `ft_iterative_power` | Potencia iterativa |
| ex03 | `ft_recursive_power` | Potencia recursiva |
| ex04 | `ft_fibonacci` | n-ésimo Fibonacci |
| ex05 | `ft_sqrt` | Raíz cuadrada entera (o 0) |
| ex06 | `ft_is_prime` | ¿Es primo? |
| ex07 | `ft_find_next_prime` | Siguiente primo ≥ `nb` |
| ex08 | `ft_ten_queens_puzzle` | Soluciones al puzzle 10 reinas |

## Cómo probar

```bash
make -C src/Piscina/C05
make -C src/Piscina/C05/ex08 && ./src/Piscina/C05/ex08/test_ex08.out
```
