# C09

## Objetivo

Crear una librería estática (`libft.a`), un Makefile con `srcs/`/`includes/` y reimplementar `ft_split`.

## Ejercicios

| Ejercicio | Función/script | Descripción corta |
|-----------|----------------|-------------------|
| ex00 | `libft_creator.sh` (+ `ft_putchar`, `ft_swap`, `ft_putstr`, `ft_strlen`, `ft_strcmp`) | Compila objetos y genera `libft.a` |
| ex01 | `Makefile` (`srcs/*.c`, `includes/ft.h`) | Build de `libft.a` con reglas `all`/`clean`/`fclean`/`re` |
| ex02 | `ft_split` | Parte una cadena según charset |

## Cómo probar

```bash
cd src/Piscina/C09/ex00 && sh libft_creator.sh
make -C src/Piscina/C09/ex01
make -C src/Piscina/C09/ex02 && ./src/Piscina/C09/ex02/test_ex02.out
```

## Notas

`ex01` usa la estructura `srcs/` + `includes/` (completada a partir de ex00).
